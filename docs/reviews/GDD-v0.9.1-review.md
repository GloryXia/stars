## 3. 平衡性问题

### B-1 隐士近乎零风险（P0）

Tier 1 微球纯被动，SDI 终点 = 20%·D0·P\_pop = 15.0 \~ 25.8%；A 类危机线 70%、内爆线 100%。Tier 3 和平微球（不点打击）终点 55 \~ 66%，Tier 2 为 35%。也就是说不碰【打击】几乎不可能进入 A 类危机，存续的 SDI 抵扣（−15 … −85）被 clamp(0) 吞掉。§13 R2 的缓解①「内卷项推高 SDI」在数值上不成立。

**建议**：内卷系数 20% → 55 \~ 65%，或改 t² 增长，让「是否投资存续」成为真取舍。M1 指标：隐士存活率不超过其他流派的 1.5 倍。

Tier 3 在 R=20 ly 时 S\_base × 可见度 = 4.0 × 10,001，SNR≥5 锁定半径远大于整张图（154 ly）。收益侧只有存续缓冲（×1.4 \~ 2.9）与孔径增益；「产能」无公式，且没有资源消耗处：点数固定 10、研发时长固定，产能无处可花。

### B-4 点数节奏与「终极执剑人」时间线（P1）

全满研发需 1,760 min = 29.3 h，超过 24 h。【打击】先点会立即自爆（126%×D0），所以终极执剑人被迫存续优先：标准特性下存续 Lv.4 于 12.6 h、打击 Lv.4 于 23.2 h 完成，余量仅 0.8 h；L0=0.88 时余量 0.22 h。该流派的实际形态是「最后一小时的一枪」，与 §4.2.1 示例 3 描述的 55–70% 高压平衡区不符。

**建议**：缩短研发时长或前置发点；纳入 M1 仿真。

### B-5 开火脉冲过弱（P1）

按 CD 连射的稳态脉冲：Lv.1 9.0%、Lv.2 9.5%、Lv.3 10.3%、Lv.4A 11.6%、Lv.4B 12.6%；四种武器同时连射 40.4%。单一武器连射远不足以「顶破 100%」，与 §4.2.1 的「防洗地」叙述不符。

**建议**：脉冲 ×2 \~ 3，或 τ\_pulse 60 → 180 min（Lv.2 稳态升至 22.6%）。

### B-6 隐匿树 Lv.2–4 边际接近零（P1）

| 配置 | 相对「Tier 1 + Lv.1」的有效发射 |
| :-- | --: |
| Tier 1 无隐匿 | 2.0× |
| Tier 1 + Lv.1 | 1.0× |
| Tier 2 + Lv.3 | 0.96× |
| Tier 3 + Lv.4 | 0.80× |
| Tier 3 + Lv.3 | 47.9× |

放气窗约每 195 min 一次，占时间 7.7%。结论：Lv.3/4 只是抵消能级跃迁带来的 ×80 / ×50 增亮（一笔税），而不是更强的隐身。

**建议**：在文档中显式写成「能级税」，并调低 S\_base 阶跃（×80/×50 → ×10/×10），或让 Lv.3/4 提供真实增益。

### B-7 点打击对微球二元化（P1）

判据 D\_strike ≥ 0.5·R\_p 即灭绝：RKV（D=6）灭 R\_p ≤ 12，存续 Lv.0–3 的最大值 7.5 全灭（Lv.3 仅靠一次性盾）；只有 Lv.4（15，最差本底 12 临界）能扛 RKV。即 2 点 + Tier 1 的 RKV 通杀一切已锁定微球，存续 Lv.1–3 对点打击无减伤。另外 B1「观测 Lv.1 + 打击 Lv.1 偏转」被「存续 Lv.1」严格占优（1 点 / −15% vs 2 点 / +8%）。

**建议**：二元判定改为按比例削减体积，或概率判定。

### B-8 窄束搜索预算（P1，设计洞察，建议写入规则）

全天窄束扫描（驻留 3τ）：观测 Lv.2 需 14.4 h，Lv.3 约 2,400 h，Lv.4 不可行；24 h 内最多 1,668 / 1,001 / 544 个指向。逐星枚举：20 ly 内约 419 颗需 6.0 / 10.0 / 18.5 h；40 ly 内约 3,351 颗需 48 / 80 / 148 h。防高频轮询的设计成立，但「猎手如何找到隐士」完全依赖旁瓣、诱饵、A 类闪光等提示源。

**建议**：把提示源作为一等设计对象，纳入 M1 指标（发现率 vs 隐匿等级）。

### B-9 灾变发生率缺失（P0）

A / B 类只有阈值没有频率，R\_persist 各档（1.0 / 2.2 / 3.5 / 6.0 / 15.0）的价值无法评估。另外 B2 对存续 Lv.1 的判定比范围 1.76 \~ 2.75、B3 对 Lv.2 为 2.50 \~ 4.97，出生本底波动直接决定能否稳过。

**建议**：每代期望次数起点 B1≈3、B2≈1.5、B3≈1、B4≈0.3（泊松），交给 M1 调参；或按 R\_persist 概率判定替代硬阈值。

### B-10 灰蛊死域永久污染（P2）

死域上限 8 ly 且永久存在；高密度档单个占图 4.1%，5 个约 20%。Lv.3 狂战能否被防住取决于 C-9 的缩球速度。

**建议**：死域加半衰期（6–12 h），上限随 d̄ 缩放。
