# 《光锥之外》首个开发切片 · 4 光年定向远征接入与多信使星泡

首个开发切片从指挥核发起定向跨星远征指令 `dispatch_expedition`（`4.00 ly` 邻星）开始。$0.10c$ 远征舰队从摇篮 A 飞向候选星 B 并在途中激发 $1.00c$ 传播衰减的信号波壳（EM + $\nu$），抵达建站后回传 `1.00c` 确认回执更新核心已确认节点数。M1 输出可复跑的时间线，M2 用 **Web-First 工程（TypeScript + Three.js/WebGL2 + HTML/CSS HUD）** 在桌面与移动浏览器中呈现结果。正式 Google 登录、海外 WSS 在线会话及万级空间分片在 M3 接入，M4 通过 Capacitor 封装 iOS/Android 辅端。[技术架构](ARCHITECTURE.md) · [GDD §9](../../DESIGN.md#implementation-and-acceptance)

## 2. M1 内核、输出与验收

### 2.1 执行顺序

1. **受理指令。** 校验纪元、请求 ID 与靶标合法性。依据当前世界/存续前置判断可否发起 `dispatch_expedition`，生成 $0.10c$ 远征轨迹、推进尾焰信号波壳计划与指挥端待确认记录；同一请求重试只受理一次。
2. **推进远征、波壳与授权。** 远征舰沿 $A\to B$ 矢量以 `0.10c` 推进，同时发射以 `1.00c` 向外膨胀并按 $1/r^2\cdot e^{-\kappa r}$ 衰减（受 $F_{\text{diss}}$ 截断）的 EM / 中微子波壳；授权沿有向链路以 `1.00c` 传播并写入 B 当地计划。远征抵达与授权均就位时在当地校验条件并激活 B 基地（零部署时长下当刻完成）。
3. **发报与收报。** B 完成接入后，以当地采样时刻生成回执，按返程链路以 `1.00c` 传播。A 收报后按来源版本与采样时刻更新已确认节点。重复报告只应用一次，迟到的旧采样保留历史。相同时间的回执和等待截止，场景先应用已抵达的回执，再处理超时。
4. **计算席位视图。** 以已确认节点计算节点数、活跃协同跨度 `active_sync_span_ly` 与冗余，以有效的有向路径计算已知可达远端数。视图保留请求状态和报告时间。合法的迟到回执可以把「超时 · 结果未确认」更新为已确认。[席位契约 · 网络视图](SEAT-CONTRACT.md#关键因果与网络摘要约束)

## 3. M2 Web-First 原型与移动端适配

### 3.1 两种视角的演示流程

1. Web-First 主场景（Three.js / WebGL2 + HTML/CSS HUD）载入公开星表和同一份合成席位时间线，初始显示摇篮 A（本征跨度 `0.01 ly`）以及已确认节点数 1。点击「向 B 派出 `0.10c` 远征（4.00 光年）」触发场景中固定的受理记录。提供暂停、快进和重播，方便观察 `0.10c` 航队推进、以 `1.00c` 外扩衰减的信号波壳及 `44.0 年` 回执边界。
2. **天球仪**在 A 端画出公开星 B 的方向、波段伪彩雾斑／准星与标签。**三维星泡图**绘制星网连线、`0.10c` 在途远征矢量箭头、随发射时刻向外匀速扩散并渐淡的多信使信号波壳（含关闭发射后的**空心波壳＋内侧暗腔**以及淡虚线理论消散界 $R_{\text{diss}}$ 参考圈）。两视角共享一个席位状态，切换时保留播放位置和当前视角可呈现的选中节点。
3. 远征抵达 B 后，在回执返抵 A 前两视角仍显示 B 为待确认，星图只按已披露证据绘制链路。成功回执于 `2640` 秒抵达后，B 更新为己方已确认节点，两视角同步更新计数并可查看光信采样和抵达时间。缺回执分支显示超时未确认。另用合成 `1 <= SNR < 5`（EM / $\nu$ 宽锥 / 单站 GW 弧）、EM $\mathrm{SNR}\ge 5$ 二维方位锁与 `N_stars >= 3` GW 三角锁验证：弱异常依托 `coarse_dir_vec3` 与 `dir_sigma_rad` 转向凝视，二维方位锁绘制无终点射线，三维星泡图只对已披露坐标的对象开放拾取。

原型随包提供合成的席位时间线，方便 PC 浏览器与手机浏览器离线演示与回归对照。客户端原型验证按播放时间应用视图。实时信息隔离由 M3 海外服务端授权和空间分片投影验证。[技术架构 §3](ARCHITECTURE.md#3-游戏客户端与海外-web-first-交付链路)

### 3.2 移动端优先与 PC 操作

手机端以星图为主，常驻视角切换、在途远征／当前确认节点数、波段消散预览开关和主要操作。轻点节点或波壳后从底部展开详情，可查看接入状态、信使通道与光信时间。底部操作和面板避开系统安全区。PC 窗口足够宽时，详情可停靠在侧栏，窄窗口沿用紧凑布局。布局切换保留播放位置、相机和当前可见选中项。

| 操作 | 手机触控 | PC 键鼠 |
| --- | --- | --- |
| 选星、查看波壳详情 | 轻点标记，展开底部详情。 | 左键单击标记，展开详情。 |
| 查看不同方向 | 在天球仪单指拖动视线，在三维星泡图单指拖动旋转。 | 在星图区域按住左键拖动。 |
| 缩放三维星图 | 双指捏合，或点按 `+` / `−`。 | 星图内滚轮，或点击 `+` / `−`。 |
| 切换视角、派出远征、切换隐匿／波段、控制播放 | 点按屏幕控件。 | 点击同一控件，或用 `Tab` 移动焦点，按 `Enter` 或空格激活。 |
| 关闭详情 | 点按关闭按钮。 | 点击关闭按钮，或在游戏获得焦点时按 `Esc`。 |

拖动超过移动阈值后由相机接管，抬手结束拖动。双指捏合取消本次点选，所有触点抬起后恢复点选。触摸或鼠标从控件、详情面板开始时由该区域处理，滚轮在详情面板内滚动内容。失焦、切后台或收到取消事件时清理进行中的手势。只有激活远征或协同确认控件才触发场景指令。
