## 1. 定位与设计支柱

**宗旨**：宇宙 / 河系尺度的“黑暗森林与宇宙文明”模拟器。它不是 4X，也不是舰队战术游戏；玩家是整个文明跨世代的宏观意志，调控因果疆域半径 $R_{\text{civ}}\in[0.01,20]\,\text{ly}$、卡尔达肖夫指数 $K\in[0.7,2.0]$、观测视场 $\Omega_A$ 与辐射特征。

**一句话**：每个文明被抽象为半径动态可变的三维球体 $\mathcal S(\vec r,R_{\text{civ}})$；银河系文明密度 $\rho_{\text{civ}}$ 是可调实验参数；原生内置 MCP，支持“人类执政官 + AI 执剑人副官 + 硅基自主文明”同场共存。

**四条涌现公理**（不设任何人工阵营规则）：
1. **物质与空间**：膨胀换体积冗余，但引发球壳摩擦。
2. **热力学暴露**：能级跃迁与表面积扩张必然产生废热，形成以光速外扩的暴露球壳。
3. **光速因果与猜疑链**：探测、通信、打击均受 $1.0c$ 限制，看到的永远是过去的光。
4. **清理与威慑不对称**：RKV $0.85c$、狂战 $0.25c$、戴森光束 $1.00c$ 的毁伤与隐蔽特征各异。

**双重大过滤器**：内源 = SDI（坍缩内卷、膨胀分裂、高危科技，§7）；外源 = B1~B4 天灾（§7.4）。

**六大支柱**
1. **同心双球**：内球 = 因果疆域（$V=\tfrac43\pi R^3$）；外球 = 光锥波前 $R_{\text{light}}(t)=R_{\text{civ}}(t_0)+c\,(t-t_0)$。
2. **膨胀 vs 坍缩二律背反**：膨胀得多星冗余与长基线孔径，代价是暴露随 $R^2$ 增长、内部延迟推高 SDI、招来狂战；坍缩混同于恒星亮点，代价是内卷与单点命运。
3. **三维球体拓扑博弈**：相离 / 相切与透镜交叠 / 大球吞小球 / 节点命中 / 狂战削蚀（§4）。
4. **文明密度参数化**：$\rho_{\text{civ}}$ 与 $(\eta,N_*,\bar d,D_{\text{map}})$ 闭合（§3.3）。
5. **MCP 双层托管**：L1 由服务端处理到期告警，L2 外部 Agent 处理策略。客户端与 MCP 共用观测、积分和权限裁定（§10、§12）。
6. **事件驱动**：半径按需计算，光锥事件按到达时间调度。文明目标包含五大平行成就，高熵死锁时可发起星际宪政公投（§9、§11）。

## 2. 科学锚点：观测、发现、抵达、控制的四重不对称

以截至 2026-11 的人类文明为唯一认知基准（$=1.00$，$K\approx0.73$）。

| 能力层级 | 人类尺度（2026-11） | 游戏映射 |
| :--- | :--- | :--- |
| 天文观测 | 可观测宇宙半径约 460 亿光年。看见恒星 ≠ 看清文明 | 星图与文明观测各有可见范围（§3、§12.3） |
| 强信号可探测 | 行星射电雷达模型约 12,000 ly [2]。SETI 试点对指定强度信号的灵敏度约 124 ly，试点未检出可信的地外技术信号 [3] | 定向信标与窄束接收的量级参照（§8.1） |
| 泄漏可探测 | DSN ≈ 65 ly、4G LTE ≈ 4 ly、旅行者 ≈ 0.97 ly [2] | Tier 1 的游戏探测标定见 §8.1 |
| 人造物最远抵达 | 旅行者 1 号预计于 2026-11-18 达到距地球 1 光日（≈0.00274 ly）[4] | $R_{\min}=0.01$ ly ≈ 3.65 光日 ≈ 632 AU |
| 载人 / 自给 | 载人约 40.7 万 km（Artemis II，2026-04）；地外自给定居点为 0 | Tier 1 微球摇篮期 |

**三条推论**：① 已知星图 ≫ 可识别文明；② 可打击半径 > 可稳定控制半径 $R_{\text{sync}}$（100 ly 外往返 ≥200 年）；③ 因果同步网的价值高于领土面积。

**三个物理混淆（模型必须规避）**：信号能传播到 ≠ 对方能检测到（1974 年阿雷西博信息 2026 年仅走约 52 ly）；理论探测上限 ≠ 全向全天候检出；探测器进入星际介质 ≠ 具备跨星扩张能力。

## 3. 空间、半径与文明密度

### 3.1 坐标与星表

世界坐标单位为 1 ly。背景星点可用 `Float32` 渲染，坐标绝对值为 120／1,000 ly 时 ULP 分别约为 $7.6\times10^{-6}$／$6.1\times10^{-5}$ ly，比 0.001 ly 的逻辑空间分辨率细至少 16 倍。M1 的求交、阈值与时间演算使用双精度中间值。

$N_*$ 颗背景恒星由服务端生成。服务端持有可占领恒星的稳定 ID、位置与自行、控制者和状态。客户端可按公开种子生成装饰星点，但可导航、可占领、可命中的真实节点须通过服务端观测权限获得（§12.3）。同一真实恒星在同一时刻最多归属一个文明。

### 3.2 半径与实际控制节点

| 形态示例 | 半径（ly） | 体积（ly³） | 截面（ly²） | 含义 |
| :--- | :--- | :--- | :--- | :--- |
| 坍缩微球／摇篮 | 0.01–0.05 | $4.2\times10^{-6}$–$5.2\times10^{-4}$ | $3.1\times10^{-4}$–$7.9\times10^{-3}$ | 通常只有一座摇篮 |
| 近邻包络 | 0.2–1.5 | 0.034–14.1 | 0.126–7.07 | 可覆盖前哨，仍可能只有一颗恒星 |
| 恒星群落泡 | 2–8 | 33.5–2,145 | 12.6–201 | 可能形成多星网络 |
| 旋臂巨泡 | 10–20 | 4,189–33,510 | 314–1,257 | 更大的交叠、暴露与同步压力 |

这些范围用于描述形态，间隔属于过渡区。体积 $V=4\pi R^3/3$ 描述因果疆域。**实际单节点或多节点**由有效受控节点数决定，即使 $R>0.2$ ly 也可能只有一个节点。中密度档均匀近似 $\rho_*=0.0125/\mathrm{ly}^3$ 时，2 ly 与 4 ly 球内的额外背景星数期望约为 0.42 与 3.35。实际星表、密度梯度、已占领状态决定结果，摇篮另计。

- 每个文明从一颗独占的摇篮星出生，初始球心即摇篮坐标。球半径决定可接入范围，不能把他者的节点或星际真空算成自己的备份。
- **M1 占领与退网默认**：完好的空闲恒星首次进入范围时可自动接入；同一时刻多方符合条件时按稳定的文明 ID 排序。主动收缩或因灾变等原因退出范围的完好节点立刻退网、失去归属，之后可重新接入。毁损节点在本纪元内不参与占领。已占领节点不能仅因对手扩球而易主。
- 摇篮损毁后，尚有节点的文明选取距原球心最近的有效节点作为备份摇篮，同距按稳定节点 ID 排序。球心不会瞬移。对所有有摇篮的存活状态，几何半径下限为 $R_{\text{floor}}=\max(R_{\min},\|\vec r_{\text{anchor}}-\vec r_{\text{civ}}\|)$。缩球、受损和护盾结算均不得因半径变化而丢弃唯一的备份摇篮。若伤害同时摧毁多颗节点，先按命中前快照确定幸存节点，再选摇篮及反算半径。迁徙从出发至落地按 §6.3、§10.3 的迁徙状态处理，落地的新球心与新摇篮同址。失去最后节点时统一走 §7 的存亡裁定。
- 节点默认等权。研发和充能的扩张加成在 M1 基线取 1，另按真实节点数测试候选收益（§15）。节点拓扑变更与几何体积变化分别结算，不能用期望星数生成损失或虚构节点。

### 3.3 文明密度

标准服 $M=240$，真人主权席位 60–120，硅基生态席位 140–180，合计 200–300。真人池每席可挂一个 MCP 副官，投票资格见 §11。采用球形星区时：

$$N_*=\frac{M}{\eta_{\text{civ}}},\qquad
\bar d_{\text{civ}}=\rho_{\text{civ}}^{-1/3}=\eta_{\text{civ}}^{-1/3}\bar d_*,
\qquad D_{\text{map}}=\left(\frac{6M}{\pi}\right)^{1/3}\bar d_{\text{civ}}.$$

$M=240$ 时 $D_{\text{map}}\approx7.71\bar d_{\text{civ}}$。厚径比 1:3 的圆柱星区在同体积下盘径约为 $9.71\bar d_{\text{civ}}$。$\bar d_*$ 为星表密度的特征间距，$d_0$ 为 §8.1 的探测标定距离。

| 档位 | $\eta_{\text{civ}}$ | $N_*$ | $\bar d_{\text{civ}}$ 及基准（ly） | $D_{\text{map}}$ 及基准（ly） | 预期环境 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 高密度 | 1:10 | 2,400 | 4–8（6.0） | 31–62（46.3） | 交叠与近距打击更常见 |
| 中密度（默认） | 1:100 | 24,000 | 15–30（20.0） | 116–231（154.2） | 中等接触频率 |
| 低密度 | 1:1,000 | 240,000 | 50–100（75.0） | 386–771（578.3） | 隔离更强 |

径向密度梯度采用 $\rho_{\text{civ}}(r,z)=\rho_{\text{core}}e^{-r/R_{\text{disk}}}\operatorname{sech}^2(z/Z_{\text{disk}})$。银心、主盘和外晕分别是高、中、低局部密度区域。约 5、20、≥50 ly 是参考特征间距，实际保护与教学按各档传播分钟数布置（§13）。

**M1 密度基线**：现有半径上限、同步半径、辐射尺度、灾害半径与死域半径沿用绝对 ly，$d_0$ 仍随 $\bar d_{\text{civ}}$ 缩放。完全位于星区内的 20 ly 球在高、中、低档的体积占比分别约为 64.64%、1.75%、0.033%，高密度档 12 ly 和 8 ly 对应约 14.0% 和 4.1%。统一缩放 $\bar d_{\text{civ}}/20$ 或独立档位参数作为对照实验。

### 3.4 时间与运动

光跨越当前档位特征间距固定为 30 分钟，即 $c_{\text{eff}}=\bar d_{\text{civ}}/(30\,\mathrm{min})$。以下时间以跨越该间距计算，实际抵达按轨迹与接收点求解。

| 信号或载具 | 速度 | 基准抵达与预警 |
| :--- | :--- | :--- |
| 光、信标、戴森光束、诱导超新星辐射壳 | $c_{\text{eff}}$ | 30.0 min，戴森攻击本身无先于命中的预警，发射前蓄能可被观测 |
| 制导 RKV | $0.85c_{\text{eff}}$ | 35.3 min，飞行前方窄锥内的光速信号最早约提前 5.3 min，能否看见仍按 §8 |
| 动能脉冲 | $0.50c_{\text{eff}}$ | 60.0 min，发射时的光速警示信号可提前 30.0 min |
| 狂战载具、诱饵、火种迁徙 | $0.25c_{\text{eff}}$ | 120.0 min，迁徙的本底速度加成及尾迹见 §5、§6.3 |

**M1 收放默认**：膨胀基准速率为 $0.10c_{\text{eff}}$，应用 §5 的 $g_0$ 修正。受损后扩张可按 §6.3 加速，上限为 $0.25c_{\text{eff}}$。缩球速率 $0.25c_{\text{eff}}$，下达指令后经过 $1\,\mathrm{min}/S_{\text{org}}$ 启动。两者在达到目标半径后停止。目标半径受能级与摇篮约束，输入只修改目标，不瞬间改半径；毁伤和迁徙的强制变化另结算。若狂战正在扩张，在可达半径及启动延迟约束下，缩球要使 $d_{\text{hit},B}\ge R_{\text{inf}}+R_B$ 才能脱离，较快的缩球速度本身不保证脱离。积分常数在 §8.2 定义，标准与闪电服寿命在 §6.2 定义。

## 4. 球体几何博弈与视角

### 4.1 相对位置与交互

记中心距为 $d$、$s=R_A+R_B$、$q=|R_A-R_B|$。以双精度中间值判定，M1 容差 $\epsilon=10^{-4}$ ly。先判 $d\le q+\epsilon$：$|d-q|\le\epsilon$ 归内切边界，同心等半径视作重合特例，其余归包含。再判 $|d-s|\le\epsilon$ 为外切，$d>s+\epsilon$ 为相离，其余为部分交叠。容差只用于分类，体积按真实几何钳制。

| 状态 | 观测与交互 |
| :--- | :--- |
| 相离 | 传播和发现按 §8。 |
| 外切 | 可发边界接触告警，交叠体积为 0，无摩擦。 |
| 部分交叠 | 可发边界接触告警，按 §7.1 累计逐对摩擦，脱离或完成双向 `[PING]` 共鸣时清除该对贡献。 |
| 内切／包含／同心重合 | 不生成普通边界接触告警，不触发部分交叠摩擦；由 §8 的实际传播路径和宿主噪底裁定泡内观测。 |

外切和部分交叠告警由接触区域生成，信息传到接收点后才可见。M1 每对采用 10 分钟滞回冷却及 0.02 ly 死区。未锁定时只暴露粗方向扇区和接触类型。精确到达时刻保留在服务端，GUI 与 MCP 在实际到达时刻向上取整的分钟边界同时发布，无精确接触时间、交叠深度、对方半径或球心坐标。接触告警不等于点打击锁定。对外暴露字段和权限见 §10、§12。

**M1 边界共鸣**：同一外切或部分交叠接触期内，双方都须向该接触的对方发出确认，且两条 `[PING]` 均实际送达。服务端以内部稳定的文明对标识和接触期关联确认，单向确认不清除摩擦。失去接触或任一方对另一方发起敌对行动时，共鸣及未完成确认均失效。

部分交叠的透镜体积为
$$V_{\text{overlap}}=
\frac{\pi(s-d)^2\left[d^2+2ds-3(R_A-R_B)^2\right]}{12d}.$$
通用求交可直接处理相离体积为 0、包含体积为较小球体积，避免同心时除以 0。摩擦只在部分交叠启用。狂战与灾变的毁伤使用真实交叠体积，和外交摩擦的适用范围不同。

### 4.2 扩张、潜伏与视角

扩张增加观测基线与灾害冗余，可能接入额外恒星，并缩短球外观测的近缘传播距离。扩张同步压力随 $R^2$ 增长，热暴露项在 $\alpha_R$ 生效时随 $R^2$ 增长，热沉与放气按 §6.3、§8 分开计算。泡内微球可尝试截获实际抵达的通信信号，收到的方向、强度和内容仍取决于波束、旁瓣、噪底与积分。

- **天球仪**：观察点在目标几何球外时，视直径为 $2\arcsin(R_B/d_{AB})$。在表面或球内时改用实际可见节点的方向，避免把不可见的目标外壳画成圆斑。
- **三维全息星泡图**：绘制装饰星点、己方疆域、已获准显示的目标和已到达波前。双方均通过 §8 裁定观测，单节点与多节点毁伤也由 §8 裁定。

## 5. 文明初始本底：四维十三项

基准 $1.00$ = 2026-11 人类；**零意识形态预设**（膨胀 / 坍缩、开放 / 封闭完全由局内操作决定）；波动 $\pm10\%\sim\pm15\%$。

**零和配平**：$\sum_{m=1}^{12}\ln X_m=\ln\mathcal D_0$，且 $\Phi_{\text{trait}}=\mathrm{clamp}(g_0M_{\text{bio}}S_{\text{org}}R_{\text{orb}}^{0.5}/\mathcal D_0,0.80,1.25)$。M1 随机本底在表列对数范围内抽样前十二项，由乘积确定 $\mathcal D_0$，超出其范围则重抽。使用由对局种子和世代 ID 派生的独立随机流。基准用例直接固定全部本底为 1。

### 6.2 点数、工程与世代时钟

标准服 $L_{\text{std}}=24$ 现实小时。闪电服预设 4 小时，允许配置为 4–6 小时。每代以 §5 的 $L_0$ 算出 $L_{\text{init}}$。

- **工程。** 五维研发逐级进行，启动时需已完成前一级和最低 Tier，扣 1 点。同一世代共用一个施工位，研发与能级跃迁均不得并行。施工位占用时拒绝新任务，不扣点。M1 允许显式取消未完成任务，已付点数与已做工程不退。同刻完工先于取消处理。工程表的耗时为基准工作量，正常每现实分钟累积 $P_{\text{pop}}I_{\text{sci}}$ 单位研发或 $P_{\text{pop}}$ 单位能级施工。完全休眠及唤醒过渡期间，两者速度均再乘 0.4。完成时才获得科技效果或 Tier，跃迁不耗点。
- **同刻顺序。** 先结算世代到期，已到期者不能收点、完工或消耗护盾续命。其余存活者先应用发点、过渡与完工，再按 §7.2 结算影响本体的同刻事件。外来已发事件的去留按 §8 与迁徙规则处理。发点、施工、死亡分别记录稳定事件标识，重放不得重复扣点或完成。

## 7. SDI（文明自毁指数）、持续冗余度与灾变

### 7.1 SDI 数值与事件状态

$$
s_{\mathrm{raw}}=\mathcal D_0\big(\Delta_{\text{density}}+\Delta_{\text{lag}}+\Delta_{\text{tier}}+\Delta_{\text{tech}}+\Delta_{\text{pulse}}-\Delta_{\text{persist}}\big)+E_{\text{fixed}}+E_{\text{overlap}},\quad
\mathrm{SDI}=\operatorname{clamp}(s_{\mathrm{raw}},0,100\%).
$$

- **结构项。** 内卷 $\Delta_{\text{density}}=20\%\cdot\min(t/L_{\text{init}},1)\cdot P_{\text{pop}}\sqrt{R_{\min}/R_{\text{civ}}}$。延迟 $\Delta_{\text{lag}}=25\%\cdot(R_{\text{civ}}/R_{\text{sync}})^2$，$R_{\text{sync}}=R_{\text{sync},0}S_{\text{org}}M_{\text{sync}}$，$R_{\text{sync},0}=1.0$ ly。能级、打击科技与存续抵扣取 §6.1、§6.3 的累计值，抵扣项在括号内取绝对值后减去。观测、信标和隐匿科技的结构负荷为零。
- **开火与动荡脉冲。** 对已发生的开火与大幅缩球求和：$\Delta_{\text{pulse}}=\sum_k A_k\exp[-(t-t_k)/\tau_{\text{pulse}}]$，$\tau_{\text{pulse}}=60$ min，初始幅值取 §6.3。它们保留 $\mathcal D_0$ 修正。
- **固定百分点事件 $E_{\text{fixed}}$。** 存续 Lv.3 完工 −30、B2 检定失败 +15、§8.3 指定的真实节点损毁 +10，使用同一 60 分钟衰减常数，事件初始幅值独立于 $\mathcal D_0$。衰减选择是 M1 基准，存续 Lv.3 的常规累计抵扣仍单独生效。启用隐匿 Lv.3 时累计蓄热时长，停用时暂停蓄热，已积累的热量不会消失。满载后每经过一现实秒累计 +0.2 个百分点，即使停用隐匿也继续累计。开始放气时清零该 SDI 项，放气完成后热沉归空。护盾重置产生 §7.2 的固定百分点偏置。上述项均先合计，再应用显示钳制。
- **交叠 $E_{\text{overlap}}$。** 仅按 §4.1 定义的部分交叠计算。每对文明分别维护起点和两端累计值。M1 每连续交叠满 10 分钟，以该时刻的相交体积为准，向每端加 $2\text{ 个百分点}\times V_{\text{overlap}}/V_{\text{self}}$。有效的双向 PING 共鸣生效、分离、转为非部分交叠或一方终止时，该对累计和计时清零。各对独立累加，边界告警的滞回只影响提示。
- **重放。** 存档保存或可从事件日志重建各类脉冲的幅值、时刻与事件 ID、憋热起止、交叠对状态、护盾库存、触发器状态和恢复偏置。事件按逻辑时刻衰减，离线与重连不重新发放。只对 $s_{\mathrm{raw}}$ 检定阈值，显示钳制不会吞掉抵扣或让后续增量从 0/100% 重新起算。

### 7.2 同刻结算、解列与护盾

同一逻辑时刻先按 §6.2 处理到期与工程，再应用点打击、灾变 B 类、狂战削蚀等外来事件。相同阶段用稳定事件 ID 排序。每个命中按命中前的几何和防御状态裁定，扣除节点、体积及护盾即时生效。已灭绝者跳过后续结算。应用同刻的形态与交叠变化后按下列规则检定破百。A 类定时检定随后执行，若新增 A 类影响则以更新后状态再检查阈值。相同事件 ID 不重复执行。

- **破百是阈值边沿。** 初始已武装，$s_{\mathrm{raw}}\ge100\%$ 时触发后解除武装，只有低于 100% 才重新武装。计时触发、伤害与研发完工都能使其越线。基准仿真必须处理连续变化导致的越线，不能依赖 HUD 刷新。
- **超过同步半径。** $R_{\text{civ}}>R_{\text{sync}}$ 触发星际因果解列。半径降至原值的 30% 并钳至 §3.2 的存活半径下限 $R_{\text{floor}}$，按 §8.3 处理被剥离的节点，产生 2~4 座失控废墟球。每座按 §8.1 的全向废墟信号 $S_{\text{beacon}}=1.0$ 发出，实际何时被发现由波前及 SNR 决定。
- **同步半径内。** $R_{\text{civ}}\le R_{\text{sync}}$ 时，若有未用免死盾，先消耗该盾并将体积减半，半径钳至 $R_{\text{floor}}$，然后按受损后的几何和其余当刻事件重算 $s_{\mathrm{raw}}$。写入校正偏置 $50\%-s_{\mathrm{raw,post}}$，在应用时使值恰为 50%，此后按 $\tau_{\text{pulse}}$ 衰减。后续无新事件且时刻不变时，重算仍为 50%。没有未用盾则内爆灭绝。
- **护盾库存。** 存续 Lv.3 首次完工发 1 层，之后不可叠加或再生，升级 Lv.4 不补发。只能抵消上条内爆或 §8.3 的本来致命点打击。点打击先用盾时，同刻后续 SDI 检定按库存已空处理。A/B 灾变的直接毁伤不由护盾抵消。灾变后的存活者仍按本节结算 SDI。B4 的 Lv.3+ 免疫是独立科技效果。

### 7.3 持续冗余度
$$\mathcal R_{\text{persist}}(R)=\Phi_{\text{trait}}\times M_{\text{red}}(\text{Lv}_{\text{persist}})\times\Big[1+\gamma_V\ln\frac{R}{R_{\min}}\Big],\quad \gamma_V=0.25$$
基准特性、$R=R_{\min}$ 时 $\mathcal R_{\text{persist}}=M_{\text{red}}=1.0/2.2/3.5/6.0/15.0$（Lv.0~4）。$R=5$ ly 时缓冲项 $\approx2.55\times$。

### 7.4 灾变检定与确定性抽样

**体积损失。** 对 A1、B1、B2 和 B3，若命中前已处于几何最小半径 $R_{\min}$，且检定判定应失去体积，则灭绝。其余存活者按表列比例削去当前体积，半径从剩余体积反算并钳至 $R_{\text{floor}}$，同步释放范围外的节点。体积下限与灭绝分别记录，不以浮点半径近似推断生死。B4 及 §7.2 护盾走各自的保命分支。首倡的主动体积代价按 §11 裁定。

**A 类内源。** 自出生起每 30 现实分钟检查存活者。仅 $s_{\mathrm{raw}}>70\%$ 时各合格类型独立抽签。A2 另需 $s_{\mathrm{raw}}>75\%$ 且 $R>R_{\text{sync}}$。同刻 A1、A2、A3 按编号执行，后续动作跳过已灭绝者。M1 初始概率仅供比较，分别为 0.10／0.05／0.10。

### 7.5 M1 场景与流派对照

- **基准时钟。** 标准 24 小时服，全本底为 1，不休眠，依次施工 Tier 2（0–1 h）、存续 Lv.1（1.2–1.45 h）、Tier 3（1.45–3.95 h）、存续 Lv.2（3.95–4.70 h）、存续 Lv.3（6–7.5 h）。随后在 8.4／10.8／13.2／15.6 h 分别启动打击 Lv.1–4，19.6 h 完工，尚有 4.4 h，实际射击仍需蓄能并通过安全检查。按 $R=R_{\min}$、无额外事件计算，完工时 $s_{\mathrm{raw}}\approx87.33\%$。第 8 点在 18 h 到账，可在打击完工后做存续 Lv.4，于 22.6 h 完工。存续 Lv.4 优先的另一可行路线，可在 22 h 完成打击 Lv.4。
- **过载。** 微球 Tier 3、打击 Lv.3、存续 Lv.0 的结构负荷为 86%，在上述基准条件下若已处于该配置，理论阈值约在出生后 16.8 h。Tier 3、打击 Lv.4、存续 Lv.0 的结构负荷 126%，即使 $\mathcal D_0=0.85$ 也已有 107.1%，应触发安全检查。有存续 Lv.4 时这套构建的静态值为 41%，仍受半径、开火、灾变等负荷影响。
- **状态与灾变验收。** 比较 $\mathcal D_0=0.85$、1.15 时注入的 −30 个百分点初值。向已有盾、同步半径内的存活体注入破百事件，验证存档后同刻重算 50%、仅消耗一层。在最小半径测 A1 抽中削蚀和 B1/B2/B3 抗灾未达标时灭绝，另测抗灾恰达阈值时通过。B4 用无 Lv.3 的 $R=1$ ly、冗余 2.151 目标与 $R=0.20$ ly、冗余 6.121 目标验证灭绝和存活，另测阈值恰为 4.5。
- **仿真对照项。** 分别调整内卷、开火脉冲、灾变概率、重建收益及交叠系数，复用种子对比发现、存活、能级完成时机和开火窗口。Tier 1 最小球在初始寿命末端单项内卷约 15%–25.8%，只表明该项低于 A 类门槛。单武器按冷却理论连射时，未乘本底的稳态峰值约 9.0–12.6 个百分点，实际能否过载要合并当前 SDI、在途上限和多武器发射节奏。参数对照及指标见 §14–15。

## 8. 探测与打击方程

### 8.1 传播路径与 SNR

记有效传播距离为 $d_{\text{path}}$。球外热辐射在 M1 可用发射端与接收端的近缘距离近似。发射球在发射时取值，接收球在到达时取值。定向信号、节点发射信号及相切、交叠、包含场景改用实际发射点到接收点的距离。M1 每个文明用其有效摇篮或备份摇篮作节点观测接收点。距离下界 $d_{\min}=0.01$ ly 仅用于 SNR 分母，传播时延使用未钳制距离。进入对方几何疆域不会令所有节点之间的距离变成零。

$$\begin{aligned}
F_{\text{th}} &= S_{\text{base}}(K_B)
\left(1+\alpha_R\frac{R_B^2}{R_0^2}\right)
\frac{P_{\text{pop}}W_{\text{em}}}{\eta_{\text{th}}}
M_{\text{stealth}}M_{\text{recoil}},\\
F_{\text{signal}} &= S_{\text{beacon}}\eta_E\eta_{\text{fab}},\\
\mathrm{SNR}_{A\leftarrow B} &=
\frac{\big(F_{\text{th}}e^{-\tau_{\text{th}}}
+F_{\text{signal}}e^{-\tau_{\text{signal}}}\big)
G_{\text{obs}}\,\mathcal S_{\text{opt}}}
{\left[\max(d_{\min},d_{\text{path}})/d_0\right]^2N}.
\end{aligned}$$

- $d_0=0.211\bar d_{\text{civ}}$，$R_0=0.20$ ly，球外背景噪底 $N=N_{\text{bg}}=4.0\times10^{-5}$。$\alpha_R$、$M_{\text{stealth}}$ 和 $M_{\text{recoil}}$ 按 §6.3 的当时状态取值。$\mathcal S_{\text{opt}}=W_{\text{em}}\eta_{\text{fab}}C_{\text{info}}$ 取接收者特性。
- 同时仅启用一种已解锁的隐匿模式。普通状态或隐匿因灾变失效时取 $M_{\text{stealth}}=\alpha_R=1$。隐匿 Lv.2 以玩家指定的轴划分前后半球，同轴点积非负用前向值，其余用排热值。Lv.3 放气及 Lv.4 的启用条件见 §6.3。重叠的热反冲取同时生效的最高倍率。
- M1 热辐射、普通微波和激光均取 $\tau=0.002\,d_{\text{path}}/\mathrm{ly}$。信标 Lv.4 星碑只在自己的引力波信号项取 $\tau_{\text{signal}}=0$，热辐射仍消光。不同波段消光系数保留为对照参数。若热辐射和独立信号走不同路径或不同时抵达，分别按各自时刻和路径计算，不合并为同一包。
- **M1 泡内噪底默认**：若发射点和接收点同处一个宿主，且发射者或接收者为该宿主几何疆域内的另一文明，取 $N=1{,}000N_{\text{bg}}$。多层包含只取同时包住两端的最外层宿主，不叠乘。此倍率用于 M1 比较观测策略，可按对局中的发现率调整。内切和包含均不生成普通边界告警。截听还需信号实际到达并落入主瓣或旁瓣。
- **标定**：中密度档、$d_{\text{path}}=20$ ly、$G_{\text{obs}}=1$、其余本底为 1，Tier 1 微球无隐匿／隐匿 Lv.1 的 SNR 含消光分别为 1.072／0.536，无消光为 1.116／0.558。无隐匿 Tier 2／3 微球为 85.76／4,288.22，Tier 3 隐匿 Lv.4 为 0.428（对应无消光 89.26／4,463.23／0.445）。

**SNR ≥ 5 的锁定距离**（中密度档，$G_{\text{obs}}=1$ 除非另注）

| 情形 | 不含消光 | 含消光 |
| :--- | --: | --: |
| Tier 1 无隐匿 | 9.4 ly | 9.4 ly |
| Tier 2 无隐匿 | 84.5 ly | 78.2 ly |

### 8.2 观测与波前时间

$$G_{\text{obs}}=G_{\text{survey}}\left[1+\eta_{\text{int}}
\left(\sqrt{\frac{\Omega_{\text{full}}}{\Omega_A}}-1\right)\right]
\left(1+\beta_R\ln\frac{R_{A,\text{baseline}}}{R_{\min}}\right),
\qquad \tau_{\text{int}}=2.5\,\mathrm{s}\ln\frac{\Omega_{\text{full}}}{\Omega_A}.$$

$\Omega_{\text{full}}=4\pi\,\mathrm{sr}\approx41{,}253\,\mathrm{deg}^2$。$R_{A,\text{baseline}}$ 是接收时已恢复的有效基线半径（§6.3）。观测 Lv.0 只可全天巡天，取 $G_{\text{survey}}=1$、$\beta_R=0$。全天球巡天的方括号恒为 1。焦点内信号按 $\eta_{\text{int}}=1-e^{-T/\tau_{\text{int}}}$ 计算，$T$ 为实际连续曝光。焦点外仅保留巡天通道。在基线半径为 $R_{\min}$ 时，稳态最窄束的增益按 §6.3 分别为 3.16／79.1／2,530／约 $10^6$。观测 Lv.4 大转向先结算 §6.3 的轨道重构延迟。

**M1 因果参考计算**

1. 热辐射等连续信号按逻辑时钟每秒取样。每个有时限的信号记录发射源、源时刻、当时位置／半径、方向／波束、强度、载荷和有效时段。M1 的 `[PING]`、定向激光信标、A1 闪光持续时间分别暂取 5 s、30 s、1 s。持续尾迹按飞行或反冲的实际时段取样。M1 以 $S_{\text{beacon}}=0.03$ 作为武器光速预警信号的默认强度。RKV 飞行前向锥半角近似 $1/\gamma$ rad，$\gamma=(1-v^2/c_{\text{eff}}^2)^{-1/2}$，只在锥内计算该尾迹。动能脉冲发射时产生 1 s 的全向警示样本。星碑、教学遗迹与 §7.2 的废墟球在有效寿命内持续发射，废墟取 §7.2 的全向强度。附带语义的信标按发射方的波束和配置旁瓣判定；未声明旁瓣时视为没有旁瓣。
2. 每个样本按 $c_{\text{eff}}$ 传播。发射点或波壳锚定于源时刻，接收点随轨迹变化，到达是传播面首次与有效接收点或近缘接收面相交。接收者运动或半径变化时，用相应轨迹分段求首个合法交点。实际样本有效窗口由传播前缘和后缘分别求交。源在发射后移动、关闭设备或灭绝，不会追改已发样本。
3. 接收方的指向、窗口、滤波及可用基线取实际接收时的状态。M1 仅在波束有效、样本已到达、目标在焦点内、接收装置可用时，每经过一秒符合条件的时间累加一秒连续曝光，首次到达的瞬间曝光仍为零。改指向、改视场、离开波束、有效期结束或中断观测时清零，曾发现的结果作为带源时刻的历史信息。样本在到达前不能积分，接收者变更指向后可以在尚有效的时间段内重新积分。
4. 发射期不以 SNR 删事件。逐接收者计算的参考实现每事件复杂度为 $O(M)$。M3 可按整个有效期内的合法可达 SNR 上界剔除，优化结果须与参考实现一致。派发规则及字段见 §10、§12。

| 接收结果 | 当前对外可见内容 |
| :--- | :--- |
| SNR < 1 | 本次观测不产生可见结果。 |
| 1 ≤ SNR < 5 | 模糊方向和强度等级，无可用于点打击的真实节点 ID、精确位置或速度。 |
| SNR ≥ 5 | 形成对已观察目标的有效锁定，提供源时刻、解算位置、速度及获准的节点标识。锁定保留 5 分钟作为 M1 默认，有效的新观测可刷新。诱饵须另外满足 $\mathrm{SNR}\cdot C_{\text{info}}\ge8$ 才确认为诱饵。 |

驻留 $3\tau_{\text{int}}$ 获得约 95% 的渐近增益。按最窄束、理想覆盖、忽略转向时间估算，全天窄束扫描 Lv.2／3 约需 14.4 h／2,400 h，Lv.4 无法在一代内扫完。24 小时内按每次 $3\tau$ 计，最多约 1,667／1,000／543 个完整指向。较强信号可更早超过阈值，全天球巡天、异常提示和有目标的逐星观测是不同的搜索策略。实测人机公平取决于同一服务端时钟、视场切换和权限约束。使用 1 s 样本演算仍需对极短驻留和大跨度转向单独验证。

**M1 复算样例**：中密度档，基准 Tier 1 隐匿 Lv.1 信号在 30 ly 处对基线半径为 $R_{\min}$ 的观测 Lv.2，巡天 SNR 约 0.58，稳态凝视约 18.5；信号未到达时不能曝光，持续到达后则可越过锁定阈值。半径 10 ly 的宿主用观测 Lv.4，基准 Tier 3 隐匿 Lv.4 微球的实际节点距为 8 ly，宿主噪底取 1,000 倍时，巡天 SNR 约 0.78，完成定向积分后可超过 5。

### 8.3 节点打击与群体毁伤

**点打击**

- M1 在发射时检查调用者持有目标节点的有效锁定、权限、冷却、蓄能与在途上限（§6.3、§10）。未锁定目标不发射点武器。发射只引用调用者已经合法获得的源时刻位置与速度进行轨迹预测，不能通过错误回包区分未获准访问的真实节点和不存在的 ID。
- 发射后记录原点 $\vec r_0$、单位方向 $\vec u$、速度 $v$、时间 $t_0$、最大航程 $D_{\text{map}}$ 和锁定节点。M1 用固定直线、目标自行的线性预测近似制导。裁定命中使用节点在该逻辑时刻的真实位置。只允许 $0\le v(t-t_0)\le D_{\text{map}}$ 的前向轨迹段，且两者最近距离不超过 $R_{\text{core}}=0.02$ ly。静止节点可先算前向投影 $\ell=(\vec r_{\text{node}}-\vec r_0)\cdot\vec u$ 和垂距 $b=\|\vec r_{\text{node}}-\vec r_0-\ell\vec u\|$，再检查 $0\le\ell\le D_{\text{map}}$、$b\le R_{\text{core}}$。仅裁定锁定节点，节点已失效或轨迹掠过真空则无损伤。迁徙途中火种为具有独立节点 ID 和轨迹的单节点目标，按 $R_{\min}$ 裁定。原指向旧摇篮的在途打击不会自动转向火种。原标定的预测残差 $\sigma_\theta=0.015\,\mathrm{rad}/(\eta_{\text{fab}}\sqrt{\mathrm{SNR}})$ 可作后续误差模型，M1 不作第二次随机偏转。
- 命中时计算有效节点的权重总和 $W$，目标节点权重为 $w_j$，M1 等权。若 $D_{\text{strike}}\ge0.5\mathcal R_{\text{persist}}w_j/W$，该节点判毁。戴森光束命中直接判毁该节点，最后节点仍先走 §7 的免死裁定。未达到强度阈值不移除节点，RKV 命中未毁节点仍使该节点隐匿失效 30 min。
- 判毁一个节点且仍有幸存节点时，从控制集合移除它并一次性记录节点损毁 SDI（§7.1）。以命中前的几何体积 $V$ 计算理论份额 $\Delta V=Vw_j/W$。新半径由 $[3(V-\Delta V)/(4\pi)]^{1/3}$ 求得，并取不小于 $R_{\min}$ 或最远幸存节点到球心距离的值。点打击最多损失一个实际节点，若另一节点仍在原边界，实际半径可保持原值。最后节点被判毁时由 §7.2 先检查未消耗护盾。护盾成功拦截即消耗一层，取消该节点的毁损并将半径降至 $R_{\text{floor}}$；原摇篮位于球心时该值为 $R_{\min}$。没有护盾时移除最后节点并灭绝。
- **旧参数对照**：旧规则的 35% 单击上限仅作回放比较。旧报告将 RKV 写为通杀所有存续 Lv.3 微球，但即使在当前 M1 的单节点式中，$R=0.20$ ly、存续 Lv.3、抗毁本底取最高 1.25 时 $\mathcal R_{\text{persist}}\approx13.12>12$，仍不满足 RKV 判毁条件。

**狂战感染与死域**

- 狂战载具以 §3.4 的速度飞往指定部署点，抵达且接触实际外围节点时建立感染球。M1 初始半径为 $R_{\min}$，以 $0.15c_{\text{eff}}$ 扩张。初始目标为当时被接触节点的控制者。感染期每 10 分钟取结算前的真实半径和交叠体积。基准削蚀比例 $p=16\%$（对照范围 12%–20%），本次体积损失 $\Delta V=p\,V_{\text{overlap}}$。无交叠则无削蚀。仅相切时交叠体积为 0。
- 同一结算前快照中，感染球覆盖的有效节点各累计 $pV_{\text{overlap}}/V_B$ 的感染进度，累计到 1 的节点移除一次，最后节点损毁按 §7。其余节点不增加感染进度。几何削蚀与感染进度分开，节点损毁后不再叠加一次点打击体积扣减。几何体积扣减后按立方根求新半径，保留 §3.2 的 $R_{\text{floor}}$，其他范围外的完好节点按 §3.2 退网。感染结束时，本次未完成的感染进度清零。
- 初始目标脱离后停止感染并结束这一攻击实例。若初始目标被该感染毁灭，则转换为半径 $\min(R_{\text{inf}},8\,\mathrm{ly})$ 的永久死域。死域半径固定，采用相同交叠与削蚀结算，作用于闯入的任何文明（含发射方）。死域寿命与上限的替代参数在 M1 对照测试。

**自然与诱导超新星**

自然 B4 以 §7.4 选出的真实恒星为源；诱导 B4 的作用点须是具有超新星资格的真实恒星，在合法航程内实际命中才触发。两者均以引爆时的位置为中心，以 $c_{\text{eff}}$ 向外传播。M1 默认有效杀伤半径为 12 ly。引爆当刻将源恒星标记为毁损并移除其节点。若源节点已被控制，先结算该节点的直接损毁，仍有节点者按 §3.2 选备份摇篮；直接失去最后节点的文明灭绝。§7.4 的 B4 冗余和免疫只适用于辐射壳，不能恢复源恒星。

传播中的辐射壳根据实际节点在抵达时的位置确定覆盖，对所有关系一视同仁。每个被覆盖的存活文明按同一 B4 事件 ID **仅执行一次 §7.4 的检定**，触及多个节点不重复扣损。

## 9. 五大平行成就（无属性加成，横向平权）

1. **同时空的对视 / 泡沫共生**（空间）：两球存活期重叠内双向 $\text{SNR}\ge5$ 退卷积，并完成 `[PING]` 互认。也可在外切或部分交叠期间维持双方共鸣 30 min，期间不向对方开火。
2. **跨世代的回响**（时间）：完整解析一座前代遗迹球 / 幽灵光锥球壳；或自身星碑球被后生代包裹或解析。
3. **深空幽灵 / 泡内潜伏者**（信息差）：全程微球态且未被其他文明识别为异常目标，记录 ≥3 个他者的膨胀与毁灭。高阶成就要求连续 20 min 处于另一文明球严格包含的泡内，期间宿主未取得关于自己的 $\text{SNR}\ge1$ 观测（§8）。
4. **雾中寻真 / 幻影筑球师**（博弈）：以 $\text{SNR}\cdot C_{\text{info}}\ge8.0$ 识破诱饵；或自己的诱饵诱使猎手开火 / 收缩真实边界。
5. **黑暗森林猎手 / 削蚀幸存者**（对抗）：猎手——抹除一个暴露坐标的文明且 2 h 内未被第三方反噬；幸存者——以多星冗余扛住单星拔除、断尾缩球阻止狂战蔓延、或火种迁徙生还。

## 10. AI 生态与 MCP 人机共存

### 10.1 五类内置 AI 原型

性格向量 $\vec P=$（能级野心，膨胀欲 $R_{\text{pref}}$，发声意愿，信任度，攻击 / 欺诈倾向）。下表是 M1 的混合对局初始配比。

| 原型 | $R_{\text{pref}}$ | 占比 | 行为 |
| :--- | :--- | :--- | :--- |
| 坍缩守望者 | $\to R_{\min}$ | ~25% | 主点观测与隐匿，尝试泡内潜伏 |
| 温和星泡者 | 0.5–3.0 ly | ~25% | 优先存续 Lv.3，相切时主动 `[PING]`，遇袭广播自己已取得的线索 |
| 旋臂吞噬泡 | $\to R_{\max}$ | ~15% | 尝试维持大半径，用多节点冗余抵挡毁伤，面临过度膨胀后的因果解列 |
| 奇点清理者 | $\to R_{\min}$ + 高打击 | ~20% | 开半球遮光，锁定大视直径目标后使用狂战或点打击 |
| 幻影造泡师 | — | ~15% | 隐蔽自身，利用大型反射薄膜诱饵引发混战 |

### 10.2 三元共存与双层托管

- **三类控制主体**：纯手动玩家与挂载 MCP 副官的玩家使用真人主权席位。内置 AI 与独立 MCP Agent 使用硅基生态席位。局内观测按相同规则披露，对外观测结果不含控制主体身份。
- **L1 脊髓反射**：服务端执行最多 3 条已授权的确定性 `IF-THEN` 规则，只读取自身状态与已抵达的告警。示例为边界接触且无共鸣时收缩半径，或收到 RKV 前向尾迹告警后转向防御。解锁对应能力并满足目的地规则后才可配置火种迁徙。每次动作仍检查科技、冷却、阶段和权限。执行不依赖外部 Agent 在线，延迟按 §12.2 测量。
- **L2 大脑皮层**：MCP 副官读取与 HUD 同口径的光锥观测，执行巡天、诱饵核验和外交。可在授权范围内改写 L1 规则，例如为已核验的诱饵设置反射豁免。撤销权限或关闭 L1 规则后，旧配置不得继续触发相应动作。
- **预警边界**：§3.4 的 RKV 时间只适用于指定距离与前向可见条件。戴森光束的波前本身没有提前预警，发射前的蓄能热信号仍可单独被观测。L1 只能利用已经到达且可见的线索。

### 10.3 MCP 接口

M3 规划提供 MCP 服务端及本地 CLI 桥接。资源字段、工具入参、权限、重试和事件披露规则见 [MCP 接口规格](MCP-v0.9.3-lean.md)。真人使用的 HUD 和 MCP 共享 §8 的可见性与服务端状态，世界方向和坐标一律在 §12.3 定义的本地坐标系中交换。

**火种迁徙（M3）**：存续 Lv.4 可选择本星区一个已经合法披露且可用作落点的真实导航节点，落点资格由服务端随导航披露授予。用落点许可请求迁徙，服务端接受时保留该落点至本次迁徙结束。未知、不可见与无效的落点使用同一错误口径。迁徙分为起步、巡航与入轨三段。起步和入轨各 10 min，分别在起点和终点结算尾焰。巡航时间为两节点距离除以 §6.3 的有效迁徙速度，球心沿航线连续移动。冷却自迁徙接受时开始。迁徙时半径归 $R_{\min}$、不能再次迁徙、扩张或开火。火种可按通常观测规则成为单节点打击目标，寿命与外来威胁照常结算。放弃原辖域时，本方未命中打击失效，已经发出的信号继续传播。入轨结束后取得新核心节点并开始 §6.3 的落地虚弱期。

预设副官人格保留 `watchkeeper_balanced`（稳态守夜与离线简报）、`singular_hermit`（隐匿与泡内潜伏）、`astrometry_auditor`（逐个检查弱异常与诱饵）、`symbiotic_diplomat`（边界共鸣与公投立场汇总）。预设只能在已经授予的权限内行动。

## 11. 宇宙重启：星际宪政公投

M4 使用服务器时钟推进阶段。首倡获接受的时刻记为 $t_0$。服务端以当时已在世至少 2 h、过去 12 h 有交互的真人主权身份生成去重快照 $E$，$N=|E|$。联署、正式公投和下一纪元密度表决共用此名单。换代、重连、关闭副官和离线均不改变身份资格或分母，之后进入纪元的身份也不加入本次名单。硅基席位没有这些投票权限。

| 阶段 | 窗口 | 规则 |
| :--- | :--- | :--- |
| 1 立宪动议 | 自 $t_0$ 起暴露 2 h | 在世真人主权文明达到 Tier 2 且解锁信标 Lv.2 或 Lv.4 后，可提交人类确认的首倡。每纪元全服两次有效首倡至少相隔 24 h，任一时刻仅有一项动议。首倡扣除发起者当前体积的 30%。若支付后的半径低于 §3.2 的 $R_{\text{floor}}$，拒绝首倡且不扣费。通过时消耗和发起一并结算。动议摘要通过宪政状态公开，发起者另以 $S_{\text{beacon}}=5$ 暴露，物理信号仍受传播和探测规则约束。 |
| 2 公民联署 | 自 $t_0$ 起 6 h，与阶段 1 的暴露重叠 | $E$ 内的身份每人可提交一次附议签名，MCP 获预授权后可代签。附议由服务器收到有效签名时计入，可同时发送遵循光锥规则的外交 `[PING]`。期满以 $\max(5,\lceil 0.15N\rceil)$ 为门槛，达标则进入辩论，否则结束。 |
| 3 白皮书与辩论 | 6 h | 公开本纪元废墟总数、平均半径、打击累计次数、背景能源熵等汇总数据。归零派和存续派的公开表态可更改，局内仍可开火。光锥内看到的球壳可显示对应阵营波纹，公开状态流不提供文明精确位置。 |
| 4 秘密公投 | 最长 12 h | 按 $E$ 为每个身份发放一份可用于此动议的匿名票据，提交须经人类确认。正式票提交后锁定。授权记录与票面分离，投票期间只公开参与率。期满且 $5T\ge3N$ 与 $2Y>N$ 同时成立则通过。窗口内若 $3Y\ge2N$，则立即通过。$T$ 为有效票数，$Y$ 为赞成票数。 |
| 5 大坍缩过渡 | 60 min | 通过的同一时刻，全服进入停火，停止新打击并取消该纪元尚未结算的敌对打击及其后续毁伤，立即结算当时存活文明的成就。纪元历史定格后可全知回放（$1{,}000\times$）。$E$ 可各投一次下一纪元密度，得票最多档生效，并列或无人投票沿用当前档。过渡完成后启动新 `EpochSeed`，继承符合 §6.3 的星碑。 |

阶段 1 的暴露是与阶段 2 并行的效果。无提前通过时，从接受动议到过渡结束最多 25 h。阶段切换按 `proposal_id` 与目标阶段去重，首倡体积只扣一次。以 60 名选民为例，40 票赞成已达到提前通过线。资格和票据去重使用持久真人主权身份，面向客户端的状态不提供身份与票面关联。

## 12. 工程实现与观测隔离

### 12.1 渲染

M2 的主要渲染路径为背景恒星点云（一个 `THREE.Points` 批次）与文明球壳和波前（`THREE.InstancedMesh`）。按能级、遮光朝向和接触状态绘制 Fresnel 辉光、新月相与干涉条纹。渲染批次与显存占用按三档星图实测。

### 12.2 服务端

- 半径在单段收放期间可惰性求值。以该段初始半径 $R_{\text{start}}$、目标半径 $R_{\text{target}}$、起点时刻 $t_0$ 和正速率 $v_R$ 计算 $R(t)=R_{\text{start}}+\mathrm{sign}(R_{\text{target}}-R_{\text{start}})\min\{ |R_{\text{target}}-R_{\text{start}}|,v_R(t-t_0)\}$。改目标或受击后以结算后的半径开始新段。
- M1 使用逐接收方参考计算。M3 可按事件的逻辑到期时间维护最小堆，依 §8 在抵达和有效窗口内结算；接收方收放或迁徙后，尚未结算的相交时刻依新轨迹更新。用于提速的剪枝必须与参考计算的可见结果一致。
- **L1 时序**：M3 以 1 Hz 扫描到期队列。同一批次仍按逻辑时刻及规定的事件顺序处理，事件只触发一次，不能使用逻辑时刻之后的观测或授权来改写先前结算。1 Hz 的理想轮询量化等待小于约 1 s，排队与处理另计。分别记录“事件到期至动作生效”和“规则计算”两段耗时及其分位数。实时告警与客户端收到消息的网络延迟另计。
- **M3 待测目标**：$M=240$ 时，含 500 个遗迹球的常驻内存低于 40 MB，单核 CPU 占用低于 0.5%，百人在线（含 MCP 连接）峰值带宽低于 50 KB/s。记录压测平台、连接与信号负载、统计窗口，以及未达标的指标。

### 12.3 观测隔离

1. 服务端持有权威受控节点与活动文明状态。只有自身数据、到达且满足 §8 披露等级的波前、规则许可的几何接触告警、以及宪政等明确的公开汇总可进入 HUD 或 MCP。碰撞告警按 §4 的范围披露，避免交叠深度、位置和半径的组合间接暴露目标的精确坐标。
2. 每一代文明以出生球心为原点，用服务端选择的 $\mathbf Q_i\in SO(3)$ 变换世界坐标，$\vec r'=\mathbf Q_i(\vec r-\vec r_{i,0})$。方向只做旋转。该变换统一显示和指令口径，共同背景星点仍可用于配准。按 §3.1 分离两套星表。客户端背景星点由公开装饰种子生成，可以用于配准坐标系，但与权威导航节点没有可推导的映射。真实节点、活动归属、出生点映射和权威随机状态保存在服务端。
3. M3 用两个账号及其 GUI／MCP 的等价请求验收可见性。验证授权撤销、接触告警、弱异常、锁定及复盘入口均按同一披露边界。用客户端种子和背景星点能还原公开装饰，但不能因此取得任一未披露的真实节点。已合法观测到的情报仍可能被玩家在场外共享。

## 13. 核心循环、HUD 与新手引导

### 13.1 5 分钟上线循环

读光锥简报与告警 → 凝视异常并核查方向 → 调整半径和 SDI → 在权限与冷却允许时行动并校阅 L1／L2 设置。离线期由 L1 响应已到告警，授权的 L2 可继续巡天与外交。

### 13.2 HUD

- **顶部**：纪元、密度、实际剩余寿命、能级、半径与体积、冗余度、可用点数和世代已发点数。SDI 同时显示总值及内卷、延迟、科技／存续、脉冲、事件和交叠分项，计算口径见 §7。
- **控制**：半径推杆预览孔径、冗余、受击截面与延迟压力。视场推杆显示实际积分进度。L1 面板显示反射规则与冷却，L2 面板管理连接、权限和简报。

### 13.3 渐进式引导

先在隔离的教学场景完成三步练习。目标节奏为 30 分钟，超时可继续完成当前步骤。临时观测和隐匿能力只在教学场景生效，演示不消耗也不赠送正式世代演化点，教学球、已发事件和研发状态均不带入正式星区。正式世代在入场时按 §6 启动自己的时钟。

| 阶段 | 目标窗口 | 演示 |
| :--- | :--- | :--- |
| Step 1 微球初醒 | 0–5 min | 将半径从 0.01 拉到 0.08 ly，分别看内卷和延迟分项。在基准状态的第 5 分钟，内卷项下降约 0.045 个百分点，但总 SDI 从约 0.072% 升至 0.185%。 |
| Step 2 第一缕星光 | 5–15 min | 使用临时观测 Lv.1 发现教学遗迹，收窄视场并保持指向，等信号到达后完成 $\mathrm{SNR}\ge5$ 的锁定。展示发射、到达和解算三个时刻。 |
| Step 3 光锥的代价 | 15–30 min | 使用临时隐匿 Lv.1，对比辐射变化。处理一次按 §8 到达的教学告警，并配置一条符合权限的 L1 反射或试接入 L2。入场后可保留提示偏好，正式星区规则仅在对应能力与权限已取得时启用。 |

**教学遗迹**：以 1.5 ly 的中心距布置固定源，场景起点开始连续发射并维持到练习结束。根据当档传播距离、噪底与消光反解发射强度，使基准观察者的巡天 SNR 为 2。观测 Lv.1 最窄视场对准后，信号抵达且连续驻留约 6.8 s 时可达到 SNR 5。按整秒累加时，第 7 个完整曝光秒锁定。三档在此中心距的光行时间约为 7.5／2.25／0.60 min，实际判定使用 §8 的路径距离。教学实例记录发射与到达时刻，不能在抵达前预积分。

**正式出生**：首代优先选择外晕稀疏区。以实测最近邻距离和当档 $c_{\mathrm{eff}}$ 计算预计光行时间，50 ly 对高／中／低密度分别约 250／75／20 min。稀疏出生降低早期接触概率。

**首代陨落**：在进行中的纪元内，私人复盘只展示该玩家自身的因果链和该玩家原有权限所及的线索，不揭示仍在活动的文明或节点的新坐标。保留先驱者微缩星碑和第二代查询自己废墟的权益。原版 $+15\%$ 初始科研启发作为 M2 的体验参数，明确持续期后再纳入正式进度。完整纪元回放按 §11 开放。

### 15.2 M1 平衡对照

标准服基线共 1,000 局，高／中／低密度分别 334／333／333 局。每局目标 240 席，采用 §10.1 的五类 AI 配比，从同一套配置和种子生成初始状态。对照方案沿用各档同一组种子，记录参数、局长和实际样本量。基准观察窗口为 24 h，并在 12 h 记录存活与发现快照。将自然到期、灾变、SDI 和交战造成的离场分别统计。

| 实验 | 对照和指标 |
| :--- | :--- |
| B-1／B-6／B-8 隐士与发现 | 对照现行内卷、隐匿、窄束与放气参数。按流派记录首次发现和锁定时间、死因与成就达成率，再比较候选内卷曲线。 |
| B-2 扩张回报 | 基线包含观测基线、抗灾冗余、传播距离和暴露。另测按受控节点增加研发或充能收益的方案，记录扩张率、半径持续时间、受击和抗灾收益。 |
| B-3／B-10 密度与死域 | 对照绝对半径、按密度缩放、分档半径配置和死域期限。记录交叠率、接触时间、有效死域并集与可维持的扩张规模。 |
| B-4／B-5／B-7／B-9 技术与生存 | 记录科技组合完成率、可用火力窗口、过载率、单节点毁伤与防御投入，以及首点前的灾变死亡率。逐项对照研发节奏、脉冲及灾变参数。 |
