# 《光锥之外》

一款围绕宇宙／河系尺度文明球演化、光锥延迟情报与多方博弈展开的宏观星际策略模拟。

星区横跨数十至数百光年。文明从一颗摇篮星起步，逐步接入少量恒星系。每个恒星系在星图上是一个有位置的节点，汇总当地的工业、观测与通信能力。

玩家通过文明球半径统一安排扩张、维持和撤收。球体相切、交叠和包含划出潜在接触与争夺的区域。实际节点提供产能和备份，接入、退网及毁伤在节点上结算，观测和指令沿实际链路传播。
